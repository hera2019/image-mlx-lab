# Image MLX Lab

本地 Qwen-Image-2.1 MLX 工作台。

页面：
```text
http://127.0.0.1:18080/web/mask-editor/
```

## 隐私

Workbench 和 Qwen server 都只监听 `127.0.0.1`，网页没有 CDN、第三方脚本或远程 API。
正常在本机浏览器中载入、生成和编辑时，图片与 Prompt 都只在本机流转。

## 顶层结构

整个页面是一套固定的三栏工作台：

- 左栏：由顶部“文生图 / 图生图 / 整图 Edit / 图片编辑”四个按钮切换工具。
- 中间：始终显示当前主图 / 当前结果。
- 右栏：始终显示图片库，用于在原图、上一代图、生成图、编辑图和中间结果之间切换。
- 底部：固定状态 / 提示抽屉。

顶部四个模式按钮只改变左栏，不替换中间和右栏。
点击右侧任意图片，只把它切换为中间当前主图，不改变顶部模式。
切到图生图或 True Edit 时，中间当前主图自动成为该模式的主图。
生成完成后，新图自动显示在中间并加入右侧图片库，旧图继续保留供比较。

## 图片编辑器：非破坏式

右侧“图片库”显示 Workbench 中所有：
- 载入图片
- 生成图片
- 编辑后保存的新图片

点击任意图片只会把它复制到中间工作画布中，原文件不变。

编辑过程只修改“草稿”。只有点击“保存为新图片”时，才创建一个新的图片文件加入右侧图片库。
原图始终保留，除非用户明确点“删除”。

右侧每张图片均可：
- 点击编辑
- 下载
- 删除

### Copy / Cut / Paste
选区中的所有像素都可 Copy 或 Cut。

剪贴板独立于当前图片，因此可以：
1. 在图片 A 选择并 Copy / Cut
2. 点击右侧图片 B
3. Paste 到图片 B

Paste 在“确定”前是一个临时浮动层，可：
- 在画布中拖动位置
- 改宽
- 改高
- 按比例缩放
- 非等比缩放
- 取消
- 确定后合并进草稿

系统始终只有一个临时浮动层，不做复杂图层系统。

### AI 局部编辑
使用：
- 当前草稿
- 当前 Mask
- Prompt
- Steps / Seed

Qwen 返回后使用同一 Mask 合成回当前草稿。
结果仍不会自动覆盖原图，也不会自动保存为正式图片；用户确认后再点“保存为新图片”。





### AI 局部编辑的上下文模式

AI 局部编辑提供四档：

- **自动（推荐）**：普通改色、局部细节优先使用高分辨率 crop；“去掉遮挡 / 恢复 / 补全 / 修复 / inpaint”等结构恢复语义会自动增加低分辨率整图参考。选区跨度很大或分布较散时也会倾向增加整图参考；接近整图时自动回退整图模式。
- **局部优先（快）**：只发送局部 crop + 局部 Mask。
- **局部 + 整图参考**：发送局部 crop + 局部 Mask + 低分辨率完整原图。局部图负责细节，整图只负责主体身份、姿态、背景、纹理连续性和遮挡关系。
- **整图（慢）**：完整原图 + 完整 Mask 一起送模。

无论使用哪一档，Qwen 的输出都不是最终图。系统最后仍用冻结的 full-size 原始 Mask 硬合成，并要求 Mask 外逐像素变化为 0。

### Mask bbox 局部送模

AI 局部编辑默认不会再把整张原图缩小后送给 Qwen。

流程：

1. 冻结当前原图和完整 Mask。
2. 计算 Mask bounding box。
3. 按目标尺寸、羽化和上下文自动外扩 padding，并把裁剪区域调整到合理宽高比。
4. 只把局部 source crop + 对应 mask crop 送给 Qwen。
5. 小局部默认会放大到约 640px 长边的安全工作尺寸；大区域仍受视觉 token / 1152 边长限制。
6. Qwen 返回后，把 edited crop 缩放回原 crop 尺寸并贴回冻结原图的原坐标。
7. 最终仍使用原始 full-size Mask 做确定性硬合成，并逐像素检查 Mask 外变化必须为 0。
8. padded crop 覆盖原图 >=72% 时自动回退整图模式。

状态抽屉会记录原图尺寸、Mask bbox、实际 crop、Qwen 处理尺寸和性能数据。

### 全局参考返回构图校正

“局部 + 整图参考”有一种模型行为：Qwen 偶尔会把第 3 张完整原图当成输出构图，返回完整画面，而不是局部 crop。
Workbench 会比较返回结果与“局部 crop / 完整原图”两种构图的结构差异：

- 更像局部 crop：直接按局部结果贴回。
- 更像完整原图：按原图归一化坐标，从 Qwen 返回图中反向裁出对应局部，再贴回原位置。
- 最后仍然使用冻结 full-size Mask 硬合成，Mask 外必须 0 像素变化。

因此不能把一张完整 Qwen 输出简单缩小后塞进局部 Mask。


### 底部状态 / 提示抽屉

- 默认收起，只保留一条紧凑摘要。
- 普通信息只写入状态历史，不主动展开。
- 文生图 / 图生图 / True Edit / AI 局部编辑等长时间任务开始时自动展开。
- 长任务完成的重要结果会保持 / 重新展开，方便查看性能与输出信息。
- 输入校验、失败、安全检查、无法打开等重要提示和错误会自动展开。
- 历史最多保留 80 条，新消息在最上方，可点击旧消息查看详情。


### 保存、草稿切换与撤销

手动编辑支持两种保存方式：

- **保存为新图**：默认方式，原文件保留；保存后新文件成为当前编辑对象。
- **覆盖当前图**：需要确认，只允许覆盖 Workbench results 图片库中的受管文件，不会写回用户原始外部路径。

编辑器记录“当前保存点”。Undo / Redo 使用同步 Canvas 快照恢复图片与 Mask；撤销后再重做必须精确回到之前状态。

如果当前草稿有未保存的像素修改，再点击右侧其他图片，会出现四个选择：

1. 保存为新图并切换
2. 覆盖当前图并切换（可覆盖时）
3. 丢弃修改并切换
4. 取消

不会静默丢弃草稿。

Paste 确认后，选区会跟随粘贴内容的最终位置与缩放尺寸，便于继续做色彩调整、裁剪或 AI 局部编辑。

画面缩放以视口中心对应的图片坐标为锚点；放大/缩小前后保持中心位置不变。


### 折叠工具与状态浮层

- 图片编辑左栏中的折叠工具在打开时会自动滚动左栏，让新展开的内容进入可见区域；尤其是位于下方的“AI 局部编辑”，不会再原地向下展开到视野之外。
- 底部状态 / 提示栏是覆盖页面内容的浮层，使用半透明玻璃背景、背景模糊、上方阴影和内高光，让用户能隐约看到其下方内容并明确感知“下面还有页面”，而不是误以为页面已经到底。
